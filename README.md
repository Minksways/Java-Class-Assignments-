Deployment Requirements
Runtime Environment: Java Runtime Environment (JRE) / Java Development Kit (JDK) version 11 or higher.
Deployment Package: Compressed workspace archive containing source classes, localized datasets, 
and compiled file artifacts. Step-by-step Execution Setup
Locate and extract your BalanceTracker.zip package file to a designated workspace directory folder.
Open your computer’s file manager and locate your standalone executable application file: 
BalanceTracker/out/artifacts/BalanceTracker_jar/BalanceTracker.jar
Open your system terminal  (such as Command Prompt or PowerShell) 
and type cd "Your_Extraction_Path\BalanceTracker\out\artifacts\BalanceTracker_jar"
And then when the directory is open in cmd use Java -jar BalanceTracker.jar

Once done you are in; note to keep text files patron patronTester handy for testing the 
error handling and do not save via exit 6 cmd till have read all inputs.
The text-based CLI Dashboard will execute immediately as an independent system console program frame, 
completely standalone with the help of CMD on any device.
