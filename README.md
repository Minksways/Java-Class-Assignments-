Features & Classes
1. Swimming (SWOLF Score Tracker)  
Tracks efficiency in water using the SWOLF system (Lap Time + Stroke Count).  

- Lap Time : Duration of lap in seconds.
- Stroke Count : Number of strokes taken during the lap.
- SWOLF Score : Automatically give results of combine count and time

2. Climbing (Grip Strength / Endurance)  
- Finger Strength : Hang tests or peak force output data.
- Relative Strength : Data assessing power to weight ratios.
- Benchmarks : Endurance hold and timing milestones.

Codes Structure
- SportsApp.java : this is the main driver application handling object creation  
initial print execute, setter modifications, and final updated results outputs.
- Swimming.java : Object definition handling swimming math, setters, getters, 
and console rendering.
- Climbing.java : Object definition handling climbing math, defaults, and  
terminology mapping.
